# External Research

Read the [supplied context contract](../references/context-contract.md), then state one research question, the decision it informs, scope, exclusions, and evidence that would change the decision.

Prefer standards, official documentation, original papers, author artifacts, pinned source code and licenses, and first-party engineering material. Record versions, dates, populations, metrics, and limitations. Use secondary sources for discovery or clearly labeled context.

Seek counterevidence. Distinguish an algorithm from its implementation, and a published benchmark from the project's actual task.

Report four separate layers:

1. observed evidence with primary citations;
2. interpretation for the supplied project context;
3. unknowns, conflicts, and applicability limits;
4. recommendation status: supported, provisional, or experiment required.

Research informs a decision; it does not silently become a project fact or reopen an accepted decision.

# Shape

Read the [supplied context contract](../references/context-contract.md), then inspect the project sources relevant to the decision.

1. Separate the problem, required outcome, non-goals, facts, resolved decisions, assumptions, unknowns, and proposed solution.
2. Challenge each material assumption: what supports it, what falsifies it, and what happens under partial inputs, ambiguity, scale, and failure.
3. Compare two to four plausible alternatives, including the smallest change or status quo when viable. Evaluate correctness, explainability, boundedness, cost, reversibility, and evidence needed to choose.
4. Assign each responsibility to a deterministic mechanism, heuristic, model inference, or human decision. State authority, confidence, validation, and fallback.
5. Decide only when evidence discriminates. Otherwise name the narrow research question or experiment that would.

Report the decision frame, alternatives, outcome or unresolved gate, rejected options, uncertainty, and preserved decisions. Stop before production design or code unless the user separately asks for them.

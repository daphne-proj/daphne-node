# Domain documentation

Read root `CONTEXT.md` if present and applicable decisions under `docs/adr/` before domain changes. Use their vocabulary; identify conflicts instead of silently changing definitions. Do not invent a glossary merely to fill a scaffold.

Until domain docs are migrated, inspect the pinned Rust source and its ADRs through the reference in `docs/migration/reference.json`. The target architecture map describes ownership only and does not redefine domain semantics.

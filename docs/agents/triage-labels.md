# Triage labels

Use the established roles on `daphne-proj/daphne`:

| Label             | Meaning                                      |
| ----------------- | -------------------------------------------- |
| `needs-triage`    | Maintainer evaluation needed                 |
| `needs-info`      | Waiting for missing information              |
| `ready-for-agent` | Specified and ready for agent implementation |
| `ready-for-human` | Requires human implementation                |
| `wontfix`         | Will not be implemented                      |
